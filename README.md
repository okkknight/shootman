# 甩锅篮球（Shootman）

一颗球、一个篮筐，目标只有一个：积功德。

每回合会给你一个位置可能很离谱、但一定存在解法的篮筐。按住空格蓄力，松手投篮；命中就弹出“功德 +1”，换一组新的小人和篮筐继续投。没进也没惩罚，球回到手里，原地再试一次。

Shootman 是一款不讲篮球技术、只讲“力度刚刚好”的荒诞像素游戏。它的乐趣来自一球一球把不可能的位置投进去，然后看功德数字不断往上长。

## 怎么玩

| 设备 | 操作 |
| --- | --- |
| 电脑 | 按住空格蓄力，松开投篮 |
| 触屏设备 | 按住页面上的蓄力按钮，松开投篮 |

## 本地运行

需要 Node.js 和 npm：

```bash
npm ci
npm run dev
```

打开终端给出的地址，通常是 <http://localhost:5173/>。

## 构建和部署

```bash
npm run build
```

静态文件生成在 `dist/`。如果要放在网站的 `/shootman/` 路径下，使用 `npm run build:shootman`。仓库目前没有确认可用的在线游戏地址。

游戏基于 Phaser 3 和 TypeScript。像素图形都由代码画出来，不依赖外部图片或音效。玩法与实现细节见[设计方案](<./《功德篮球》MVP 游戏设计方案.md>)；文档保留了早期名称“功德篮球”，游戏现在叫“甩锅篮球”。
